# Frontend

Aplicación React (Vite) de la plataforma de cursos de Elegant Music Studio.

```bash
npm install
npm run dev      # desarrollo en http://localhost:5173
npm run build    # compilación de producción
npm run lint
```

Necesita el backend corriendo. La URL de la API está en `src/services/api.js`.

La documentación completa (instalación, variables de entorno, API y estructura) está en el [README principal](../README.md).
